Getting started

Choose Setup EXE or Portable EXE from the latest public release.
Run Setup to install, or double-click the downloaded portable EXE.
Choose Display, Window or Region. Press Start, then stop to save your MP4.

Need audio?

Microphone and system audio are still undergoing real-device testing. Audio-enabled builds are test builds, not stable public downloads. For testing information, see GitHub Actions.

Common questions

Which Windows versions are supported?

Arssyut is built for Windows x64 and is being tested on Windows 10 and Windows 11. Hardware and Windows graphics capabilities can affect capture support.

Installer or portable EXE?

The installer adds a Start menu shortcut. The portable download is one executable you can launch directly. Both are built from the same application.

Can I record my microphone and system audio?

Those features exist in a separate audio-enabled testing build, but have not yet completed public release acceptance. We will not label them stable before real-device validation is complete.

How do the buttons stay up to date?

Both pages check GitHub Releases when opened and resolve the newest published version. Public previews are labelled Preview; drafts and internal CI artifacts never appear as official downloads.
