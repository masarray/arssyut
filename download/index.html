Common questions

Which Windows versions are supported?

Arssyut is built for Windows x64 and is being tested on Windows 10 and Windows 11. Hardware and Windows graphics capabilities can affect capture support.

Should I choose Installer or Portable EXE?

Choose the Setup EXE for Start menu integration, or the standalone Portable EXE to launch without installing. Both must come from the same official GitHub Release.

Can I record my microphone and system audio?

Yes. System audio and microphone recording are implemented in the audio-enabled Windows application, with source toggles and volume/mute controls. Webcam recording is not implemented yet.

How do download buttons stay up to date?

The page reads published GitHub Releases and links to the newest eligible Setup and Portable EXE files. Previews are labeled, and draft releases and internal CI artifacts are never represented as stable downloads.
