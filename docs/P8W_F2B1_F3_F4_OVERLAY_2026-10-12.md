Date 2026-10-12. **DRAFT — CI + real hardware pending.** Parent: #124 exact user-recorded SHA `11b8976528c5d00d36e41859514510fed261565f`. Never merge before A/V acceptance.

## Physical evidence/decision
The supplied 46.38s 1080p60 MP4 showed moving camera PIP and 2782 encoded frames, 2 Pause/Resume, 0 StageFull, 0 video skips and 0 GPU copy errors; however after Stop the GUI showed a camera placeholder with Webcam toggle ON. This proves real capture/PIP, **not** post-Stop preview freshness. Source audit: preview-only renderer uses D3D11 EVENT query and DONOTFLUSH polling but previously did not submit the readback command batch after recorder relinquished the GPU context. F2B.1 sends bounded nonblocking `Flush()` only on the idle preview owner and after the safe ownership return. It does not call a synchronous GPU Map or stall 60fps encoding. Hardware must verify sequence growth after Stop, no camera reopen or lamp flicker.

## F3 — Camera PIP
- Follows ADR-011 and earlier F1–F5 plan; UI uses real output profile instead of unlocking old placeholder.
- Four corners, masks Circle / RoundedRectangle / DiagonalTopLeftBottomRight / **DiagonalTopRightBottomLeft (top-right and bottom-left rounded, top-left and bottom-right square)**. The latter matches the user's explicit Bandicam-style choice. Preserve the opposite diagonal option as an independent type.
- Size (15–40% output width), margin (0–12%), corner radius (0–50% of short half extent), border (0–12px), opacity (0–100%), mirror, source crop-to-cover. Circle is isotropic in output pixels. `OutputOverlayProfile` finite/bounds validation before camera starts.
- Legacy schema 6 had a mock BottomRight position while real MP4 always rendered TopRight. Versioned schema 7 defaults old profiles to observed TopRight, then persists explicit choices.
- Native bridge ABI 12 extends the existing start struct with a versioned validated profile; no historical reserved bits repurposed; same GPU compositor draw, immutable per session.

## F4 — Independent Logo Overlay
- Dedicated Settings navigation directly below Camera. PNG with alpha is required, no unsupported WebP promise.
- Bounded file size <=16MB, decoded pixels <=8,388,608, dimensions <=4096, WIC PNG verification and PBGRA premultiplication; decode *once during recorder Preparing*, upload to an immutable D3D11 texture SRV, retain until recorder teardown. Missing/invalid logo disables logo only; desktop+AAC continue.
- Enable, choose PNG, preview, five placements (four corners and Center), size (3–40%), margin and opacity. Logo independent of camera, composed in the SAME HLSL output Draw, no additional full-frame pass.
- UI picker and persistence are next-session. Camera source changes while recording continue to be disallowed. One MP4 writer/QPC audio remains intact.
